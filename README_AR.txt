Cool Panda — ملفات البداية

محتويات الحزمة:
- index.html: واجهة الموقع وتسجيل الدخول ولوحات الحسابات.
- supabase_schema.sql: الجداول وسياسات الصلاحيات.
- initial_accounts.json: بيانات 831 حساب مستخرجة من ملف HTML الأصلي.

مهم: هذه نسخة بداية تحتاج إعداد مشروع Supabase ونشر الواجهة قبل أن تصبح موقعاً عاماً. لا تضع Service Role Key في المتصفح أو ترسله لأي شخص.

الإعداد مرة واحدة:
1) أنشئ مشروعاً في https://supabase.com ثم افتح SQL Editor.
2) الصق محتوى supabase_schema.sql وشغّله.
3) من Project Settings > API انسخ Project URL و anon/publishable key.
4) افتح index.html من جهازك، ضع الرابط والمفتاح في شاشة الإعداد.
5) أنشئ حسابك بالبريد وكلمة المرور ثم أكّد البريد إذا طلب Supabase ذلك.
6) من SQL Editor نفّذ أمر ترقية حسابك إلى admin بعد استبدال YOUR_LOGIN_EMAIL ببريدك. لا تجعل المستخدمين الآخرين Admin.
7) سجّل الدخول. استورد ملف Excel/CSV من لوحة الأدمن. يجب أن يحتوي على عمود username، وعمود coins اختياري، وurl اختياري.

استيراد الحسابات الأولية:
- ملف initial_accounts.json به كل الحسابات الـ831 من ملفك الأصلي.
- لتحويله إلى Excel/CSV أو استيراده، افتح الملف في محرر جداول أو حوّله إلى CSV بالأعمدة username,url,coins.
- يمكن أيضاً استخدام ملف Excel يومياً من لوحة الأدمن؛ الاستيراد يعمل upsert حسب username ولا يحذف سجل الزيارات.

التحديث اليومي:
1) حدّث ملف Excel بالأسماء والـCoins.
2) ادخل الموقع بحساب الأدمن.
3) افتح لوحة الأدمن > اختر ملف Excel > استيراد الملف.
4) الحسابات الجديدة تضاف، والحسابات الموجودة تتحدث Coins/URL.
5) سجلات الزيارة والتواصل لا تُمسح.

ملاحظات أمنية قبل النشر العام:
- لا تنشر الموقع قبل تنفيذ SQL وسياسات RLS واختبار حسابين مختلفين.
- اجعل تسجيل الأدمن يدوياً من SQL فقط. لا تمنح صلاحية admin لأي مستخدم عادي.
- النسخة الحالية تسمح بتعديل رسالة الترحيب في ملف المستخدم الشخصي؛ لتكون رسالة عامة موحدة لكل المستخدمين يفضّل إضافة جدول app_settings وسياسة admin قبل الإطلاق.
- ملف index.html الحالي واجهة أولية متصلة بـSupabase مباشرة بمفتاح anon فقط؛ لا تستخدم مفتاح service_role في الواجهة مطلقاً.
- يوصى بتفعيل تأكيد البريد وحدود محاولات الدخول ونسخ احتياطي دوري.

النشر:
يمكن رفع مجلد المشروع إلى GitHub ثم ربطه باستضافة Static مثل Netlify أو Vercel. بعد النشر اضبط Supabase Auth > URL Configuration على رابط الموقع المنشور. لا تعتبر الموقع منشوراً قبل إتمام ذلك واختبار تسجيل الدخول من جهاز آخر.
